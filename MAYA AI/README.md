# MAYA AI — Common Folder

Ithu **Windows OS-kku common**.

```
MAYA AI/
├─ Model/      → AI brain
├─ Engine/     → CPU / GPU / NPU
├─ voice/      → Tamil / English voice
├─ persona/    → Maya personality
├─ config/     → settings
├─ memory/     → offline + online memory
├─ logs/       → records
└─ scripts/    → launchers
```

OS-kku thevaiyana files mattum:
- `WINDOWS APPLICATION\windows\`

## Rules

- Offline AI brain local; news / tech info mattum internet-la edukkalam
- Online AI separate
- **Maya = command only** — nee solluratha mattum seiyum, thana ethuvum pannaadhu
- Online → Offline ✅ | Offline → Online ❌
- Personal details laptop-la mattum 🔒
- Edit / delete / important action → permission kekkum ⚠️
