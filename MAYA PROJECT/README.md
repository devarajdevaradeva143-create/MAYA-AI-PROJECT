# மாயா ஏஐ தமிழ் திட்டம்

## இது என்ன?

மாயா ஏஐ என்பது உங்கள் கணினியில் இயங்கும் ஒரு தனிப்பட்ட உதவியாளர். இது உங்கள் குரலைக் கேட்டு, பதில் சொல்லும். தமிழிலும் ஆங்கிலத்திலும் பேசலாம்.

## முக்கிய அம்சங்கள் (Features)

### 1. அரட்டை (Chat)
- கேள்விகளுக்கு பதில் சொல்லும்
- தமிழ், ஆங்கிலம், தங்கிளிஷ் ஆதரவு
- உங்கள் குரலில் பேசலாம் அல்லது தட்டச்சு செய்யலாம்
- பதில் சொல்லும் போது நிறுத்த / மறுபடி முயற்சி செய்யலாம்

### 2. குரல் (Voice)
- குரலில் கேட்டு பதில் சொல்லும்
- தமிழ் குரல் பதில் (Piper + SAPI)
- ஆங்கில குரல் பதில்
- கை தட்டல் (clap) மூலம் எழுப்பலாம்
- "மாயா" என்று சொல்லி எழுப்பலாம் (wake word)

### 3. கணினி கட்டுப்பாடு (PC Control)
- கோப்புகளை திறக்க / மூட
- இணையதளம் திறக்க
- கணினியை பூட்டு / நிறுத்து
- 22 வகையான செயல்கள்
- ஆபத்தான செயல்களுக்கு உறுதி கேட்கும்

### 4. கணினி கண்காணிப்பு (Monitoring)
- CPU, RAM, GPU, NPU நிலை
- பேட்டரி நிலை
- டிஸ்க் வைப்
- கணினி இயங்கும் நேரம்
- நேரடி நிலை காட்சி

### 5. ஆங்கில ஆசிரியர் (English Teacher)
- 4 நிலை பாடங்கள்
- AI உருவாக்கிய பாடங்கள்
- முன்னேற்றம் சேமிக்கும்
- தமிழ் விளக்கத்துடன்

### 6. பாதுகாப்பு (Security)
- PIN வைத்து பாதுகாக்கலாம்
- Windows Hello முக அடையாளம்
- குரல் அடையாளம் (voiceprint)
- பாதுகாப்பு பதிவேடு (audit log)

### 7. மொபைல் இணைப்பு (Mobile Connection)
- ஆண்ட்ராய்டு போனில் இணைக்கலாம்
- Wi-Fi மூலம் இணைப்பு
- போனிலிருந்து கணினியை கட்டுப்படுத்தலாம்
- திரை பார்க்கலாம், தட்டலாம், தட்டச்சு செய்யலாம்
- கோப்புகளை பதிவிறக்க / பதிவேற்ற செய்யலாம்

### 8. தbojil / அறிவு (Knowledge)
- PDF, குறிப்புகளை சேமிக்கலாம்
- தேடல் (search) செய்யலாம்
- ஆங்கில + தமிழ் தேடல்
- உங்கள் ஆவணங்களிலிருந்து பதில் சொல்லும்

### 9. மொழிபெயர்ப்பு (Translation)
- ஆங்கிலம் ↔ தமிழம்
- உள்ளூர் AI மூலம் மட்டும்
- இணையம் தேவையில்லை

### 10. தனிப்பட்ட உதவியாளர் (Personal Assistant)
- நினைவூட்டல் (reminders)
- நேரம் பார்க்க
- தினசரி திட்டங்கள்

## எப்படி வேலை செய்கிறது?

- கணினியில் ஒரு சிறிய AI மூளை (qwen3.5-2b-FLM) உள்ளது
- உங்கள் குரலை கேட்க மைக்ரோஃபோன் உதவுகிறது
- பதில் சொல்ல ஸ்பீகர் உதவுகிறது
- கணினியை கட்டுப்படுத்தும் (ஃபைல் திறக்க, மூட, etc.)
- மொபைல் போனிலிருந்தும் இணைக்கலாம்

## யாருக்கு?

- தமிழ் பேசும் எவருக்கும்
- கணினியை எளிதாக இயக்க விரும்பும் எவருக்கும்
- தனிப்பட்ட உதவியாளர் வேண்டும் எவருக்கும்

## எங்கே இயங்கும்?

- கணினியில் (விண்டோஸ்) முதன்மையாக
- மொபைல் போனிலும் (ஆண்ட்ராய்டு) இணைக்கலாம்
- இணையம் இல்லாமலும் வேலை செய்யும்

## பாதுகாப்பு

- உங்கள் தனிப்பட்ட தகவல்கள் கணினியிலேயே இருக்கும்
- இணையத்திற்கு அனுப்பாது
- குரல், முகம் அடையாளம் கணினியிலேயே சேமிக்கும்
- PIN வைத்து பாதுகாக்கலாம்

## மொழிகள்

- ஆங்கிலம் (English)
- தங்கிளிஷ் (Tanglish - தமிழ் + ஆங்கிலம்)

- மேம்படுத்தப்பட்ட தமிழ் குரல்
- மேம்படுத்தப்பட்ட தமிழ் பதில்
- மொபைல் இணைப்பு மேம்பாடு
